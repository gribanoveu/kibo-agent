## Три тезиса, из которых растёт всё остальное

1. **Ядро не знает про UI.** Агентный цикл уже написан так: сервис репортит наружу
   через sink (`Arc<dyn Fn(Event) + Send + Sync>`), а в Tauri-события это превращает
   только слой команд. Значит цикл переносится без переписывания, а тестируется без
   окна — см. [03-architecture.md](03-architecture.md).
2. **Turn — это машина состояний, а не блокирующий вызов.** В Atlas уже есть пауза на
   подтверждении инструмента с возобновлением (`PendingApproval` → `ToolCallDecision`
   → `ResumePoint`). Это то, что позволяет turn'у пережить закрытие окна, вернуться
   к сессии через сутки и ждать человека сколько угодно, не держа поток.
3. **Переносится инфраструктура вокруг цикла, а не список инструментов.** Инструменты
   в Atlas заточены под документацию (AsciiDoc-шаблоны, артефакты, диаграммы).
   Переносится форма границы `execute_tool`, гейтинг и логирование — конкретные
   инструменты пишутся под кодинг заново, кроме файловых.
